## 📌 About the Project

**MySeat** is a movie ticket booking backend application developed using **Spring Boot**. It provides REST APIs for managing movie information, theatre shows, user authentication, and ticket bookings. The application uses JWT authentication and role-based access control to help secure API endpoints.
